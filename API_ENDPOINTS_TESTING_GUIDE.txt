================================================================================
          RESTAURANT POS & ORDER MANAGEMENT SYSTEM - COMPLETE API GUIDE
================================================================================
This document provides a complete, module-wise catalog of all API endpoints in
the system from scratch for testing, API client collection (Postman/Insomnia),
and automated integration testing.

Base URL: http://localhost:8080
Content-Type: application/json
Authorization Header: Bearer <JWT_TOKEN>

================================================================================
MODULE 0: AUTHENTICATION & REGISTRATION (/api/auth)
================================================================================

1. System Admin Registration
   POST /api/auth/register
   Headers: Content-Type: application/json
   Request Body:
   {
     "username": "admin1",
     "email": "admin@restaurant.com",
     "password": "Password123!",
     "fullName": "Main System Admin",
     "outletId": "3fa85f64-5717-4562-b3fc-2c963f66afa6"
   }
   Response: Status 200 OK (Admin object)

2. User Login (Obtain JWT Token)
   POST /api/auth/login
   Headers: Content-Type: application/json
   Request Body:
   {
     "email": "admin@restaurant.com",
     "password": "Password123!"
   }
   Response: Status 200 OK
   {
     "token": "<JWT_BEARER_TOKEN>",
     "role": "ADMIN",
     "username": "admin1"
   }

MODULE 1: ADMIN MANAGEMENT (/api/v1/admin) [Role: ADMIN]
================================================================================

1. Get All Admins
   GET /api/v1/admin
   Headers: Authorization: Bearer <JWT_TOKEN>
   Response: Status 200 OK (List of Admins)

2. Get Admin By ID
   GET /api/v1/admin/{id}
   Headers: Authorization: Bearer <JWT_TOKEN>
   Response: Status 200 OK (Admin object)

3. Create New Admin
   POST /api/v1/admin
   Headers: Authorization: Bearer <JWT_TOKEN>
   Request Body:
   {
     "username": "outlet_admin_1",
     "email": "outlet1@restaurant.com",
     "password": "Password123!",
     "fullName": "Outlet Manager Admin",
     "outletId": "3fa85f64-5717-4562-b3fc-2c963f66afa6"
   }
   Response: Status 201 Created

4. Update Admin Details
   PUT /api/v1/admin/{id}
   Headers: Authorization: Bearer <JWT_TOKEN>
   Request Body:
   {
     "username": "outlet_admin_1_updated",
     "email": "outlet1_updated@restaurant.com",
     "password": "NewPassword123!",
     "fullName": "Updated Admin Name",
     "outletId": "3fa85f64-5717-4562-b3fc-2c963f66afa6"
   }
   Response: Status 200 OK

5. Delete Admin
   DELETE /api/v1/admin/{id}
   Headers: Authorization: Bearer <JWT_TOKEN>
   Response: Status 244 No Content

6. Toggle Admin Active Status
   PATCH /api/v1/admin/{id}/toggle-active
   Headers: Authorization: Bearer <JWT_TOKEN>
   Response: Status 200 OK
